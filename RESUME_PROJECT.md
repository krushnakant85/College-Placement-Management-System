## 📝 2–3 Line Project Descriptions

### Option A (Full-Stack Focus)
> Engineered an end-to-end College Placement Management System using Node.js, Express, MySQL, and Vanilla JavaScript, integrating an isolated Java SE Eligibility Engine via inter-process streaming. The platform automates candidate qualification screening, corporate drive scheduling, and recruitment pipeline tracking across 8 normalized relational tables.

### Option B (Backend & Architecture Focus)
> Architected a high-performance campus placement platform with a Node.js REST backend, MySQL relational database, and an independent Java SE computation microservice communicating over standard I/O. Enforced strict data integrity via foreign key cascades, check constraints, bcrypt password encryption, and zero-downtime JavaScript fallback evaluation.

### Full-Stack & General Software Engineering
- Architected and delivered a full-stack campus placement platform using **Node.js, Express.js, MySQL 8.0**, and **Vanilla JavaScript**, automating placement drives for 50+ candidates and corporate recruiters.
